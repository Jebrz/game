## 5. 已知问题（按优先级）

1. **采掘培训在正常游玩中几乎无法开始（阻塞培训流程）**。种子 79 复现：开局铁矿为 0（课程需铁矿 6）；采掘导师只有石磊、赵铮（技能 ≥ 55），二人都是出勤小组的采掘工，小组出勤后（第 35～400 分钟）始终「没有可用导师」。勘探课程同理（导师白芷、秦望都在小组中）。建议方向（需再确认，不要降低职业要求）：允许报名后进入「等待导师返航」状态、在导师返回列车时授课；或让小组在有学员等待时安排导师留车；同时核对课程材料对开局的可达性。修复后用正常界面重跑「培训→第三组→出勤交付」。
2. 原住民许可、分享产出与无矿星的正常界面验证尚未完成（规则测试已覆盖）。
3. 首次交付约在第 140 分钟（一次探索 + 采矿 + 返航的固有耗时）；新手节奏下起始星使用新制运输机的比例约 15/20 种子。
4. 用开发服务器（`npm run dev`）跑长时间界面测试时，修改源码会触发页面刷新并中断测试：长测请用 `npm run build` 后 `npx vite preview --port 4173`，访问 `http://localhost:4173/game/star-train/?seed=79`。
5. 本地标签 `dungeon-backup-2026-11-04` 未能推送（代理拒绝），远端以 `backup/dungeon-game` 分支为准。
