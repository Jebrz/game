# 星空列车 · 当前有效设计

> 本文件只记录**最新有效**规则。「已确认设计」是玩法决定；「临时数值」是原型参数（集中在 `src/config/balance.ts`、`src/config/content.ts`），可以调整，不是定案。
> 未在此列出的系统视为尚未设计；不要凭空扩展剧情、战斗或世界观真相。

## 0. 已废弃方案（不要再实现）

| 废弃 | 现行替代 |
| --- | --- |
| 地下城游戏、修仙成长 | 星空列车生存经营；个人成长 = 基因链序列 + 职业培训 |
| 玩家设计地面工厂、地表传送带、冶炼/初步加工、货站流水线 | 运输机直接采矿运回原料；加工只在列车内的生产队列中进行，不铺传送带 |
| 运输机机载初步加工 | 已取消，不要加回 |
| 玩家逐组指派矿点 | 小组自主选择探索与采矿；玩家用收购奖励、事件选择、列车政策引导 |
| 贡献点支出需玩家审批 | 贡献点归小组共有，小组自主决定支出，无审批窗口 |
| 培训必须有在列车上的空闲导师才能报名；采掘课程消耗铁矿 | 可报名等待导师，出勤小组导师返回后离组留车授课、空缺递补；采掘课程只耗能源 |
| 「敌意满格立即失败」 | 敌意不直接判负；镇压/夺权/战斗为后续内容 |
| 单颗星球 + 固定倒计时 | 2～3 颗星的航线 + 沿航线追赶的灾变前锋（由慢到快） |
| 灾变 2400 分钟加速到 1.2（首站做完培训/造船后第二站只剩约 80 分钟就预警） | 3600 分钟加速到 1.6：前期较慢、后段更紧 |
| 小组数量固定 2 个、组队按背景职业 | 动态新增小组；组队按职业资格（背景职业不变） |
| 整片领地一次性采矿许可 | 按矿点签订的许可协议（有效期 + 开采上限）；旧存档的整片许可仍兼容有效 |

## 1. 定位（已确认）

单人、中文、电脑浏览器（鼠标键盘）。玩家是被神秘规则选中的列车长，带领人类幸存者驾驶旧列车沿古老星际轨道撤离灾变。实时运行，可暂停/1×/2×/4×/8×；暂停冻结一切模拟。氛围艰难但有希望；生活区暖色、外部星空冷色；列车侧面剖视、星球俯视地图；程序绘制，不依赖外部素材。

## 2. 列车与乘客（已确认）

- 开局 30 人：列车长、5 名负责人（副手/工程/科研/医疗/后勤）、24 名乘客。名单为**临时测试名单**（含年龄，全部成年）。
- 车头 + 5 节可用车厢（居住×2、后勤生活、工程货运、科研医疗）+ 2 节封闭车厢（未开放）。
- 列车岗位按背景/负责人自动分配；普通岗位允许低技能低效工作；医疗岗位有技能门槛。列车保留最低运营人员（临时值：工程 2、后勤 2、医疗 1）。
- 生存：食物、氧气、能源、疲劳、健康；医疗自动治疗；正常流程无随机死亡。
- 情绪：士气 / 失望 / 敌意分开；个人等权汇总；持续高失望累积敌意，降低失望不会立刻清除敌意；显示原因。
- 私人武装机器人：显示数量、状态、威慑、维持耗能；威慑不降低敌意；交易站内禁止暴力。

## 3. 职业、小组与培训（已确认）

- 每名乘客：**背景职业**（不变）、**职业资格**（对应技能达到门槛）、**当前岗位**（组内名额 / 列车部门 / 培训 / 授课，同一时间只有一个）。
- 列车长规定每组职业人数；乘客自行组队、推选组长；**一人只属于一个小组，组内只占一个名额**；负责人与列车最低运营人员不出勤；未满 18 岁不出勤。
- 编组调整为**增量**：只释放多出的、补充缺少的；小组贡献点、运输机、升级与历史不随人员变化；人员不足时显示缺口，不来回抢人；出勤中的组返航后再调整。
- **动态新增小组**：有可分配的公共备用运输机，且空闲合格乘客满足职业要求时自动成立；不占用列车长座机、小组私有备用机、已预约换装的运输机；新组贡献点从 0 开始，不发免费资源；不能为成立新组偷偷降低要求。
- **培训**：脱产课程（驾驶/勘探/采掘/工程；医疗等严格资格暂不开放）需要培训位与合格导师；学员与授课导师不提供原岗位产能，组员脱产时该组不可出勤；技能逐分钟获得，取消保留已得部分、重报不重复领取、材料每人每课程只付一次；疲劳/健康/能源不足自动暂停。**导师可用性**：导师只从现有乘客中产生（不凭空生成）；合格导师都在出勤小组时允许先报名进入「等待导师」（材料照付、占培训位、学员留在原岗位、课程不计时）；小组成员被选为导师时（回到列车且不在卸货）离组留车授课，原小组空缺按编组规则由空闲合格人员递补，无人递补则显示缺口；授课结束导师成为空闲人员；列车上有空闲导师时优先使用、不拆小组。在列车上的小组有缺口时会自动尝试递补。报名名单把已被新组计入其他名额的人排后并提示。在岗学习只提升已有资格的技能、只在实际工作时，不授予新资格。培训不提高配给、医疗优先级或忠诚。

## 4. 探索、矿点与小组决策（已确认）

- 低级列车探测仪只揭示迹象；小组实地调查确认矿点；结果同步全体。界面区分「尚未发现矿点」与「调查后确认无可采矿产」。
- 作业位置：运输机抵达部署时才取得，先到先得；返航交货期间保留，超时释放；采空释放；等待有上限，不无限等待。
- 小组决策综合收益、航程、燃料、运载、成员能力、风险、组长性格；**可交流原住民领地内的未确认迹象**：调查不需要许可（开采才需要），确认结果帮助列车长决定是否协商，因此即使已知同类开放矿点也保留较高信息价值（已建立联系时更高），仍受航程、燃料、灾变时限、风险与组长性格约束；决策日志写明选择或暂不调查的原因；探索按信息价值（已知同类可用矿点时降低、列车短缺且未知时提高、连续探索未带回原料时衰减、推进剂紧张时降低）；列车短缺提高对应采矿评分；理由需具体。

## 5. 运输机、制造与机库（已确认）

- 每组一架主运输机；新机是独立实体（唯一编号、无燃料、空货舱）。
- 制造与加工共用一条生产队列、工程产能与能耗；公共订单优先，小组订单在后（保留进度）；列车长可把公共订单提前。
- 材料在下单时扣除并记在订单上，取消原样返还；遵守「零件优先保障主驱动」。
- 机库泊位：出勤、备用、座机、建造中都占位。
- 新机完工为备用：列车长订单为公共备用（分配/换机/配属/新组）；小组订单归该组、只由该组领取。换机要求返航、卸空；可预约返航后换装；旧机转备用，不销毁。列车长不能征用小组出资的运输机。

## 6. 经济（已确认）

- 交付时原料转入列车库存，按「基础收购价 + 需求奖励」给小组记贡献点；同一批次只结算一次。
- 贡献点由列车发行，不是外部货币（外部货币为星币，只在交易站使用）。
- 小组自主购买：运输机升级、基因强化（需研究、样本、医护、适配度、承载上限、恢复期，消耗真实库存）、自主订购运输机。
- 推进剂（运输机）与轨道燃料（列车）分开。应急合成推进剂只是死锁恢复手段，不应成为常规补给。

## 7. 灾变、航线与星球（已确认）

- 灾变前锋沿航线追赶，速度平滑由慢到快，有加速提示；换星球不重置；停泊交易站期间暂停；列车始终快于前锋。
- 航线：起始星（固定、安全、富矿，保证维修与首段燃料）+ 1～2 颗随机星 + 公共交易站；可跳站（燃料按航程）；出发前显示燃料缺口与到达后的灾变预估。
- 星球的资源情况（富/贫/无矿）与原住民情况（无/可交流/敌对）分别随机；开局一次生成并随存档保存，读档不刷新；每颗后续星至少有一种取得下一段燃料的途径。
- 阶段总结在抵达最终交易站并完成补给或维修后出现。

## 8. 探索事件与原住民（已确认）

- 需要重大投入、外交或风险的地点才提交玩家决策；发现时暂停一次，进入待办列表，可稍后处理（发现小组继续其他工作）。
- 选择时扣投入；小组到现场作业、成果随返航入库一次；召回中断保留进度、投入不退；开始前取消原样退还；离开星球未完成事件作废；同一地点只生成一个事件。
- 原住民关系每星独立：尚未接触 / 可交流 / 合作 / 警惕 / 敌对；只因具体行为变化并记录原因。无翻译时只能以物易物；协商许可需研究翻译。领地内调查迹象不需要许可，只有开采需要。许可按矿点、有限期限与开采上限；小组只在有效许可内作业；分享产出在结算时扣出份额，贡献点只按留存部分。敌对区域只做禁区、警告与绕行，不实现战斗。

## 8.5 召回与离站燃料（已确认，按现有代码核实）

- 召回：所有外出小组立即返航，携带已采原料（不再继续开采）；货物在回车后卸货（约 6 分）结算才入库；卸货中的小组仍算未归。生产队列在召回期间照常加工（原料入队时已扣）。
- 解除召回：小组恢复自主出勤；「逼近」阶段只接能在灾变安全时限内完成的目标；「危险边缘」起不再出勤。推进剂由列车库存共享，先出发的组先加满。
- 离站：主驱动修复 + 下一段轨道燃料 + 全员归队；燃料不足不能离站（强行离站只遗留未归人员，不补燃料）。
- 「灾变召回」面板的离站燃料判断只读推导，不自动取消召回、送燃料或派遣小组；召回始终一键可发。

## 9. 存档（已确认）

带版本号；自动存档 + 手动槽位；保存完整世界状态（小组行动、作业位置、货舱批次、制造与培训进度、事件、许可、关系、随机数状态）；读档不重发奖励、不重复扣费；旧版本存档必须可迁移，不要求清档；不能重新随机覆盖已生成的星球。当前版本 v6。
