# 六泊位机库预览（开发预览）

只用来检查机库美术、运输机比例和出航/归队动画；**不接入正式玩法，也不参与构建和发布**（`npm run build` 只打包 `index.html`）。

## 打开方式

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/hangar-preview.html`。

操作：右侧（窄屏时在下方）选泊位「上侧 1–3 / 下侧 1–3」，也可以直接点画面里的泊位；然后按「出航」或「归队」。「重置」会立刻停止所有动画，六架运输机都回到机位。不能用的按钮会变灰。

## 实测位置（背景图 1376×768 像素）

- 三列泊位中心线 x：246 / 688 / 1130。
- 上侧：外平台 y 12–131，门口 y 131，停机坪黄框 y 163–285（中心 224），机舱内墙约 y 322。
- 下侧上下镜像：门口 y 633，外平台 y 633–752，停机坪中心 y 543。
- 门口外框宽 261，净宽约 252；六个门口一样宽。
- 预览画面在图片上下各延伸 22% 的高度，用来看运输机飞离平台后淡出。

## 比例冲突（已知）

按要求「门口两侧各留 10%–15%」，翼展应为约 189 px，对应机长约 163 px；但外平台沿航向只有约 113 px，放不下整机。两个条件不能同时满足，所以按外平台定了保守尺寸：

- 翼展 118 px、机长约 102 px。
- 停在平台上时两端各留约 5 px，离门口约 9 px。
- 门口两侧余量约 27%（比要求宽）。
- 停机坪黄框（163×122）和机舱都放得下。

如果希望运输机更大，需要把外平台在美术上加长约 50 px，或者接受停在平台上时机身伸进门口。

## 图层

门口净宽比翼展宽很多，门口处没有上方结构挡住飞船，所以运输机直接画在背景之上，没有加前景遮挡层。
