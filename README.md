# 暗影地牢

一个可以直接在浏览器里玩的 2D 俯视角像素风地下城游戏，全中文界面。
基于 **Vite + TypeScript + Phaser 3**。所有图像（角色、怪物、瓦片、特效）和音效都在运行时用代码生成，**不依赖任何外部素材**。

## 启动方法

需要 Node.js 18 及以上版本。

```bash
npm install
```

```bash
npm run dev
```

然后在浏览器打开终端里显示的地址（默认 <http://localhost:5173/>）。

构建与预览生产版本：

```bash
npm run build
```

```bash
npm run preview
```

预览默认地址为 <http://localhost:4173/>。`npm run build` 会先做 TypeScript 类型检查，再输出到 `dist/`。

## 操作方式

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动（支持斜向） |
| 空格 | 挥剑攻击；剑气还能劈碎敌人的弹幕 |
| P / Esc | 暂停 / 继续（暂停时按 Q 返回主菜单） |
| M | 静音 / 取消静音 |
| 回车 / R | 胜利或失败后重新开始 |
| Esc | 结算界面返回主菜单 |

主菜单按回车、空格或点击鼠标开始游戏。

## 玩法

- 一共 **3 层**地牢，每层都是随机生成、彼此连通的房间与走廊，有墙壁碰撞。
- 第 1、2 层：找到发光的**下行楼梯**，踩上去就进入下一层（下楼时回复少量生命）。
- 第 3 层是**魔王巢穴**：最深处的红色大房间里沉睡着 **暗影魔王**。进入房间或攻击它都会让它苏醒，击败它即获胜。
- 生命归零就失败，可以立即重新开始。
- 迷雾会遮住没去过的区域，走进一个房间就会照亮整间；右上角小地图记录已探索的地方（金色是楼梯，红色是魔王）。

### 敌人

| 敌人 | 行为 |
| --- | --- |
| 史莱姆 | 慢慢靠近，蓄力（变红）后扑向玩家 |
| 蝙蝠 | 飞行轨迹飘忽，突袭频繁 |
| 骷髅法师（第 2 层起） | 保持距离，蓄力后发射紫色法球 |
| 暗影魔王 | 环形弹幕、蓄力冲撞、召唤蝙蝠；血量降到一半后狂暴，攻击更快更密 |

敌人发现你时头顶会出现 “!”。没有直线视野时，它们会沿地图寻路追击。

### 物品

- **金币**：击败敌人掉落，靠近会自动吸过来。魔王会掉一大堆。
- **红色药水**：每层随机放置，敌人也有概率掉落，每瓶回复 35 点生命（生命满时不会拾取）。

## 项目结构

```
src/
  main.ts            游戏入口与 Phaser 配置
  constants.ts       常量（瓦片索引、玩家数值等）
  dungeon.ts         随机地牢生成（房间放置 + 最小生成树连通 + 额外环路）
  textures.ts        程序化绘制的像素素材与动画
  sfx.ts             WebAudio 合成音效
  scenes/
    BootScene.ts     生成素材
    MenuScene.ts     开始页面与操作说明
    GameScene.ts     地图、玩家、敌人 AI、战斗、物品、迷雾、胜负
    UIScene.ts       HUD（生命/金币/关卡/小地图/魔王血条）、暂停与结算界面
```
