# 星空列车（第一阶段原型）

中文单人星空列车生存经营游戏。你是被神秘规则选中的列车长，带领 30 名幸存者驾驶旧列车，沿古老星际轨道在灾变「灰烬潮」到来前撤离，前往公共交易站休整。

基于 **Vite + TypeScript**，界面为 DOM + Canvas 程序绘制，不依赖外部素材。

## 在线试玩

- 星空列车试玩版：<https://jebrz.github.io/game/star-train/>
- 原地下城游戏（保持不变）：<https://jebrz.github.io/game/>

两款游戏在同一个 GitHub Pages 站点的不同路径下。`.github/workflows/deploy.yml` 会把地下城从当前线上版本的提交（`59092fa`）原样重新构建到 `/game/`，把本分支构建到 `/game/star-train/`；部署前逐个比对线上地下城文件，不一致就中止，不会覆盖旧游戏。推送本分支会自动更新试玩版。

存档：两者同域名共享浏览器存储，但星空列车只使用 `startrain.` 开头的键，地下城不使用浏览器存储，互不覆盖。

## 第一阶段流程

列车苏醒 → 起始星球「灰岩星 K-7」：扫描（只揭示迹象）→ 小组自主调查与采矿 → 车内加工零件、修复主驱动 → 制造燃料（可选：制造一架运输机并分配给小组）→ 灾变逼近时召回 → 在「航线」面板选择下一站 → 1～2 颗随机星球（可跳过）→ 抵达回声交易站完成一次补给或维修 → 旅程总结（之后可继续在站内查看列车）。

**节奏（原型参数）**：1× 速度下 1 真实秒 = 2 游戏分钟。灰烬潮前锋沿航线追赶，推进速度由慢到快：开局 18 Mm/小时，约 40 小时内平滑加速到 72 Mm/小时；列车航速 180 Mm/小时。
- 起始星球：前锋约第 1640 分钟才抵达，脚本试玩中通常停留 1100～1400 分钟（1× 约 9～12 分钟）。
- 第二颗星球：通常可停留 230～420 分钟；第三颗：130～380 分钟（取决于前面停留多久）。
- 航段 360～470 Mm，约 2～2.6 小时，每段需 9～12 单位轨道燃料（每 40 Mm 1 单位）。
- 整段旅程约 30～41 游戏小时（1× 约 15～21 分钟真实时间，可加速）。

## 已实现

- **列车与乘客**：车头 + 5 节可用车厢（居住×2、后勤生活、工程货运、科研医疗）+ 2 节封闭车厢（标注未开放）。30 人（列车长、5 名负责人、24 名乘客，**临时测试名单**），含职业、技能、健康、疲劳、情绪、基因适配度。岗位按职业自动分配，普通岗位低技能可低效工作，医疗岗位有技能门槛 40。
- **编组**：列车长规定每组各职业人数，乘客自行组队；负责人与列车必需运营人员（工程 2、后勤 2、医疗 1）不出勤；一人不进多个小组；不满足时显示缺少什么。默认 2 个小组。
- **扫描与探索**：低级探测仪只给迹象范围；小组实地探索确认（含一处“迹象微弱、无矿”的迹象）；发现自动同步；一个简短的非阻塞事件「古代轨道信标」。
- **作业位置**：大矿区多位置；抵达部署时才取得；返航交货保留 120 分钟（界面显示剩余时间），过期释放；采空释放；等待最多 40 分钟后重新评估，不会无限等待。
- **小组自主决策**：综合收益、航程、燃料、运载空间、成员能力、风险与组长性格（稳健/进取），状态与理由可见（如“选择较近矿点以降低运输成本”“因燃料不足返航”“等待其他位置释放”）。列车推进剂告急时小组会优先采冰晶。
- **运输机**：开局采集型、探索型各一架；运载量、采矿效率、航速、油耗、耐久与例行维护；可购买升级「扩容货舱」「强化钻头」。运输机推进剂与列车轨道燃料分开。每架有唯一编号（TJ-01…）、用途与产权。
- **运输机制造与机库**（「运输机」面板）：
  - 可制造「运输型」运输机：维修零件 5、铁矿 10、铜矿 6、辉晶 4，标准工时 120 分。与加工配方共用同一条生产线、工程产能与能耗（18 kWh/小时），暂停时不推进。
  - 列车长用公共库存下单（同时最多一单，防止连点重复）；小组用贡献点 160 自主下单，材料同样从公共库存扣除，贡献点不能代替材料。
  - 队列顺序：公共订单在前，小组订单在后；被插队的小组订单保留已完成工时。
  - 材料在下单时扣除并记在订单上；取消原样返还材料与贡献点，已耗能源与工时不退。小组订单只能由该组取消。
  - 遵守「零件优先保障主驱动」政策，制造和扩建都不会动用受保护的零件。
  - 机库初始 3 个泊位；出勤、备用、列车长座机都占泊位，建造中的运输机下单即预留泊位。可扩建两次（各 +1）：Ⅰ 零件 3 + 铁矿 12、60 分；Ⅱ 零件 4 + 铁矿 16 + 铜矿 6、90 分。
  - 新机出厂无推进剂、空货舱、耐久 100，进入备用：列车长订单为公共备用，由列车长分配给小组（换机）或配属列车长；小组订单归该组，只由该组领取。
  - 换机要求小组已返航、不在卸货、旧机货舱已清空；小组出勤时可「安排返航后换装」（该机为其保留，可取消）。旧机转为备用，保留升级、耐久与燃料，不会销毁。
  - 小组只在明确需要时自主订购：没有主运输机、主运输机耐久低于 40，或货舱长期装满且新机运载量更大；同时要有预算（价格 + 20 余量）、材料与泊位，每组同时一单，理由写入决策记录。
  - 列车长只能配属或分配列车公共运输机，不能征用小组出资的运输机。
- **贡献点**：交付时货物转入列车库存，按「基础价 + 需求奖励」结算，每批次只结算一次；列车长可调需求奖励并即时显示新价格；小组自主购买（运输机升级 vs 基因强化），显示理由、费用与结果，无审批窗口。超出基本任务半径的航程由小组额度支付。
- **加工**：维修零件、轨道燃料、运输机推进剂、电解制氧；入队即预留原料，取消退还，无负库存。
- **研究与基因**：「采掘适应序列解析」解锁「采掘适应序列·一阶」（贡献点 + 生物样本 + 能源 + 在岗医护 + 适配度/健康/疲劳 + 承载上限 1 + 恢复期 90 分钟）；未实现序列显示为未开放。
- **生存**：食物、氧气、能源、疲劳、健康；医疗自动治疗；正常流程无随机死亡。
- **情绪**：士气、失望、敌意分开；个人等权汇总；持续高失望累积敌意，降低失望不会立刻清除敌意；显示影响因素。
- **私人武装机器人**：数量、状态、威慑、维持耗能、待机/巡逻；威慑不降低敌意；敌意满值不直接判负。
- **灾变「灰烬潮」**：前锋沿航线追赶列车，推进速度平滑加快（不会突然跳变），并在加速到 35%/65%/90% 时提示。顶栏显示阶段、预计到达区间与「加速中」；预计按加速曲线精确推算，再给出越来越窄的区间。换星球不重置，停泊交易站期间暂停。每颗星球单独有逼近预警与危险边缘提示（首次危险边缘自动暂停）；前锋抵达停靠星球后车体持续受损，车体归零才失败。
- **航线（「航线」面板）**：起始星球 + 1～2 颗随机星球 + 回声交易站。显示每个节点的远程情报（可能不准确）、里程、航程、燃料需求、到达时间与届时灾变预估、燃料缺口；可跳过不值得停靠的星球（燃料按实际航程计算）。访问记录与跳过记录会保留。
- **星球随机生成**（开局时按种子一次生成并随存档保存，读档不会刷新）：资源情况与原住民情况分别随机。
  - 资源：富矿（铁/铜/冰/辉晶齐全）、贫矿（只有冰与辉晶，或只有金属 + 遗留燃料舱）、无矿（只有遗迹/异常信号：遗留燃料舱与零件、可加速研究的调查数据、空残骸）。
  - 原住民：无；可交流（调查「人工信号」后建立联系，可交易燃料/辉晶/推进剂/生物样本，或协商领地内的采矿许可）；敌对（扫描后显示禁区，禁区内迹象和矿点不可接近，小组自动绕开，靠近边缘可能收到驱逐警告；不实现战斗）。
  - 保底：起始星球固定为安全富矿；每颗后续星球都至少有一种取得下一段燃料的途径（禁区外的辉晶与冰晶、遗留燃料舱，或可交流原住民），不会需要先去下一站才能起飞。
  - 区分「尚未发现矿点」与「调查后确认：无可采矿产」。
- **召回与离站**：紧急召回，查看各组位置、返回预计、载荷、推进剂、未归人员；离站需主驱动修复 + 轨道燃料 10 + 全员归队；可强行离站（遗留人员与运输机，敌意大增，需确认）。
- **交易站**：本段航线终点。停泊费、每小时停泊费、买卖、车体与运输机维修、站内禁止暴力、灾变追赶暂停（不清零）、旅程总结（含各星球访问记录）。
- **存档**：版本号（当前 v3）；自动存档（每 60 游戏分钟与阶段变化）+ 2 个手动槽位；完整保存小组行动、矿点占用、货舱批次、制造进度、订单归属与预留、机库泊位与随机数状态，读档后暂停。旧存档读取时自动升级，无需清档：v1 补运输机编号与归属、机库容量取 max(3, 现有运输机数)；v2（单星球旧航程）迁移为「原星球 → 交易站」两节点航线，灾变剩余时间保持不变、离站仍为 10 单位燃料，可继续完成旧阶段。体验 2～3 颗星球的新航线需要新开局。

## 未实现 / 限制（后续阶段）

- 完整外部星球毁灭、竞争期限、最后出口关闭、留居结局。
- 镇压、夺权事件与战斗；列车长亲自探索玩法；封闭车厢解锁剧情；离开交易站后的航线。
- 小组数量固定为 2，没有动态组建新组；新运输机只能用于换机、备用或配属列车长。只有一种可制造型号（运输型）。
- 离开交易站后的航线、更大的星域地图未实现。
- 完整 10 人负责人候选池与人物故事（当前为临时测试名单）。
- 重要探索场景只有一个简短事件。
- 所有数值是原型参数，未做最终平衡；脚本通过不代表新手体验已经平衡，需要真人试玩确认。
- 只有一种原住民交互形式（交易与采矿许可）；敌对原住民只有禁区与警告，没有战斗、谈判或事件链。
- 重要探索场景仍只有起始星球的「古代轨道信标」一个简短事件。
- 浏览器存档使用 localStorage，隐私模式下可能不可用（界面会提示）。
